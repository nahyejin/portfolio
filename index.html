"MCP가 뭔데?" — 사용자가 모르는 기술을 자연스럽게 쓸 수 있도록, 연동 화면 전체를 처음부터 설계 · 2026.06–현재

SLIDE 01 기획 배경 & 나의 역할 +

MCP라는 새로운 프로토콜을 일반 사용자에게 "어떻게 보여줄 것인가" — 레퍼런스 없는 화면을 처음부터 기획

Quetta 시리즈 내 위치 — 세 번째 제품

기존 Quetta 시리즈는 "사용자가 직접 분석하는" 도구였지만, Quetta Data MCP는 사용자의 AI(ChatGPT, Claude 등)가 대신 데이터를 호출하는 완전히 새로운 구조입니다. 사용자 입장에서 MCP라는 개념 자체가 생소하기 때문에, "기술을 설명하는 화면"이 아니라 "연동이 자연스럽게 완료되는 경험"을 설계하는 것이 핵심 과제였습니다.

SLIDE 02 "MCP를 모르는 사용자"를 위한 연동 가이드 설계 +

6종 LLM 환경별 4-Step 연동 가이드 — 기술 용어 대신 "지금 뭘 하면 되는지"에 집중

MCP 연동은 개발자에게도 익숙하지 않은 작업입니다. ChatGPT는 Actions 설정, Claude Desktop은 JSON config 파일 수정, VS Code는 Extension 설정 — 같은 "연동"이지만 LLM마다 방법이 전혀 다릅니다. 이 차이를 사용자가 직접 파악하게 두지 않고, 각 환경에 맞는 단계별 가이드를 화면 안에서 바로 제공하는 구조를 기획했습니다.

6종 LLM 환경별 연동 가이드
기획 시 고민한 UX 포인트
진입 장벽 낮추기인증키 복사 → 해당 LLM 환경에 붙여넣기 — 복잡한 설정 과정을 "복사&붙여넣기" 수준으로 단순화
환경별 분리같은 MCP 연동이지만 LLM마다 설정 방법이 다르므로, 환경을 먼저 선택하면 해당 가이드만 노출
질문 가이드"기간 + 키워드 + 분석 방향 + 결과 형태"로 질문하는 방법까지 안내 — MCP 연동 후 실제로 어떻게 써야 하는지까지 커버

레더링 분석 텍사노미 C-D MAP (중심성·차별성)
레더링 분석 방법론 텍사노미
목적소비자 심층 데이터를 기반으로 제품의 속성과 관련된 소비자 가치를 체계적으로 분석해 마케팅 전략에 활용할 텍사노미 사전을 구축.
주요 전제레더링(Laddering) 기법으로 구매 행동을 속성(Attribute) → 혜택/결과(Consequence) → 가치(Value)로 계층 연결해 심층 분석. 속성이 제공하는 이점과 심리적·정서적 만족을 도출해 핵심 동기를 파악.
구축 방법① 속성 — 제품 고유의 물리적·기능적 특징 텍스트(예: 무설탕 음료) / ② 혜택·결과 — 소비자에게 제공하는 직·간접 이익 텍스트(예: 다이어트에 도움) / ③ 가치 — 최종 심리적·개인적 만족 텍스트(예: 자신감 있는 삶).
기대효과속성에서 가치로 이어지는 구조적 분석으로 소비자 내면의 욕구·동기를 파악하고 브랜드-소비자 간 정서적 유대감을 형성. 가치까지 연결되는 통찰로 정교한 마케팅·제품 개발 전략을 도출.
C-D MAP · 중심성(Centrality)–차별성(Distinctiveness) 맵
목적브랜드를 중심성(시장 대표성)과 차별성(고유 특성)으로 평가해 포지셔닝과 전략을 수립.
주요 전제브랜드는 중심성과 차별성을 동시에 추구하며, C-D 맵은 매출·가격 등 사업 성과와 직접 연결되는 도구 (하버드비즈니스리뷰, 니라지 다와 교수).
분석 방법중심성(X축) — 자사 브랜드 화제어 Top100이 전체 브랜드 화제어 Top100에 포함되는 비율(시장 대표성). 차별성(Y축) — 전체 대비 자사에서만 나타나는 고유 화제어 Top100 개수 비율(경쟁사 대비 차별화).
4분면 해석① 열망 브랜드(중심성 高·차별성 高, 예: 벤츠·BMW) / ② 이례적 브랜드(중심성 低·차별성 高, 예: 테슬라·미니) / ③ 주변 브랜드(중심성 低·차별성 低, 예: 미쓰비시·마쓰다) / ④ 주류 브랜드(중심성 高·차별성 低, 예: 포드·쉐보레).
기대효과시장 내 위치를 파악하고 경쟁사 대비 전략적 강점·개선 방향을 도출해 브랜드 전략(광고·커뮤니케이션·포지셔닝)을 수립.
